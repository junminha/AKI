## Local HTTPS

각 프로젝트의 의존성을 설치한 뒤 `start-all-https.ps1`을 실행합니다. 서버 인증서와 개인키는 보안상 저장소에 포함되지 않습니다. LAN 접속용 공개 CA 인증서는 `AKI-LAN-인증서` 폴더에 있습니다.
